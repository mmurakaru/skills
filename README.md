# skills

A collection of agent skills that extend capabilities across planning, development, and tooling.

## Planning & Design

**prior-art** - Spike a topic in its prior art and first principles before a PRD session: surfaces the established primitives, canonical prior work, and the one essential mechanism for a context/topic.

```
npx skills@latest add mmurakaru/skills/prior-art
```

## Development

**pr-review** - Ranked GitHub PR review (max 3-5 findings, blocker/consideration/nit), paste-ready for GitHub. Supports a pluggable org overlay for stack-specific conventions.

```
npx skills@latest add mmurakaru/skills/pr-review
```

**pr-feedback** - Address reviewer feedback on a PR end-to-end: verify each claim, fix, test, then push and reply after approval.

```
npx skills@latest add mmurakaru/skills/pr-feedback
```

**fix-flaky-tests** - Reproduce, diagnose, and fix flaky Playwright e2e tests using stress testing and pattern matching.

```
npx skills@latest add mmurakaru/skills/fix-flaky-tests
```

**capture-component** - Capture a cropped PNG (or scroll GIF) of any web app UI element for PR screenshots.

```
npx skills@latest add mmurakaru/skills/capture-component
```

## Writing & Knowledge

**curating-bookmarks** - Review, declutter, and reorganize Chrome bookmarks.

```
npx skills@latest add mmurakaru/skills/curating-bookmarks
```

**to-slack-message** - Draft a short, non-verbose Slack message from the current task: one-line intro, categorized bullets with permalinks, tagging relevant people when appropriate.

```
npx skills@latest add mmurakaru/skills/to-slack-message
```
